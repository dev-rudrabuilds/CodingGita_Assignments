Section A: Short Answer Questions
Q1. What is JavaScript?
Ans :- JavaScript is a high-level, dynamically typed programming language used to add interactivity and behaviour to web pages and applications.

Q2. Who created JavaScript and in which year?
Ans :- JavaScript was created by Brendan Eich in 1995 while he was working at Netscape.

Q3. What was the original name of JavaScript?
Ans :- The original name of JavaScript was Mocha; it was later renamed LiveScript and then JavaScript.

Q4. Is JavaScript the same as Java? Give one major difference.
Ans :- No, JavaScript and Java are different programming languages; JavaScript is mainly used for web interactivity, while Java is a general-purpose, class-based language.

Q5. What does it mean when we say JavaScript is a high-level programming language?
Ans :- A high-level language uses human-readable syntax and hides complex machine-level details, making programming easier.

Q6. Is JavaScript a compiled language or an interpreted language? Explain briefly.
Ans :- JavaScript is traditionally called an interpreted language, but modern engines use JIT (Just-In-Time) compilation to execute code efficiently.

Q7. Name the JavaScript engines used by the following browsers.
Ans :- Chrome – V8; Firefox – SpiderMonkey; Safari – JavaScriptCore (JSC).

Q8. What is Dynamic Typing in JavaScript?
Ans :- Dynamic typing means a variable can hold values of different data types during program execution without declaring its type explicitly.

Q9. What is the main difference between a static website and a dynamic website?
Ans :- A static website shows mostly fixed content, while a dynamic website can change content or behaviour based on user interaction, data, or conditions.

Q10. Name the three pillars of Front-end Web Development and write one line about each.
Ans :- HTML – Structure; CSS – Styling and presentation; JavaScript – Behaviour and interactivity.

Q11. What is the difference between Frontend and Backend?
Ans :- Frontend is the user-facing part of an application, while Backend handles server-side logic, databases, authentication, and data processing.

Q12. What is Node.js?
Ans :- Node.js is a JavaScript runtime that allows JavaScript to run outside the browser, especially for server-side development.

Q13. Explain ECMAScript. What is its relation with JavaScript?
 :- ECMAScript is the standard/specification that defines the core features of JavaScript, while JavaScript is an implementation of the ECMAScript standard.
